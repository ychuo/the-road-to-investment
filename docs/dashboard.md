# 学习仪表盘

按自己的节奏前进。这里汇总每课完成清单和带编号即时测验的本地记录。

<LearningDashboard />

## 如何记录进度

1. 完成课程阅读和练习；
2. 勾选课程底部的全部完成项；
3. 回到本页查看阶段进度；
4. 测验提交后会记录正确率；“再做一次”会清除该题记录；
5. 里程碑作业仍需使用[作业中心](/homework/)的量规单独验收。

::: tip 数据说明
仪表盘只使用浏览器 `localStorage`，不需要账号，也不会把你的学习状态或财务信息上传到服务器。
:::
