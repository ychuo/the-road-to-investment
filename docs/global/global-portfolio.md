全球组合不是把国家名称收集齐，而是用尽可能少的组件，获得与你目标匹配的风险暴露。

## 先决定三个层级

### 1. 股票与防守资产比例

这仍由目标和风险边界决定。不要因为增加了全球市场，就提高原本无法承受的股票比例。

### 2. 股票内部地区比例

选择市值加权、固定地区比例或核心加卫星。记录偏离全球市场权重的理由。

### 3. 每个暴露的实施载体

最后才比较境内基金、互联互通或境外基金。路径应考虑合规可得性、跟踪、费率、税务和维护难度。

## 一只全球基金方案

**优点**

- 成分和地区自动调整；
- 再平衡工作较少；
- 不容易频繁追逐地区表现；
- 账户和记录更简单。

**局限**

- 指数可能高度偏向当前最大市场；
- 难以独立控制本地与海外比例；
- 单一基金的渠道、额度或运营变化影响更大；
- 需要确认是否真正包含新兴市场和小盘股。

## 多地区拼接方案

**优点**

- 可以明确控制中国、美国、其他发达市场和新兴市场；
- 更方便匹配已有持仓；
- 可能选择更适合各地区的实施渠道。

**局限**

- 容易重叠或遗漏；
- 需要地区再平衡；
- 产品、汇率、税务和账户更复杂；
- 更容易主观追涨杀跌。

## 债券是否也要全球化

股票全球化主要为了分享多地区企业增长。债券在个人组合中常承担稳定器和目标匹配角色，因此外币债券带来的汇率波动可能抵消稳定作用。

评估时问：

- 债券服务的是人民币目标还是外币目标；
- 是否进行汇率对冲；
- 对冲成本、误差与工具是否透明；
- 海外债券增加的信用和利率分散是否值得复杂度；
- 本地高质量债券是否已满足组合角色。

没有必要为了形式上的“全球化”让每个资产类别都跨境。

## 检查组合重叠

假设同时持有：

- 全球股票指数；
- 标普 500 指数；
- 纳斯达克 100 指数；
- 全球科技主题。

看似四只基金，实际可能反复增加同一批美国大型科技公司的权重。需要汇总：

1. 前十大公司穿透权重；
2. 美国市场总权重；
3. 科技及相近行业权重；
4. 单一货币或收入来源；
5. 与本人职业的相关性。

## 教学用决策树

1. **是否有至少十年以上目标？** 否 → 先回到目标与低波动资产。
2. **基础组合是否已稳定执行？** 否 → 先简化，不急着跨境。
3. **全球化解决什么集中风险？** 说不清 → 暂不增加。
4. **合规路径、费用与税务是否查清？** 否 → 继续研究。
5. **一只广泛基金能否完成任务？** 能 → 优先评估简单方案。
6. **多组件是否有明确额外价值？** 有 → 写出比例与再平衡规则。

1. 家庭当前地区与货币暴露；

4. 一只基金与多组件方案比较；

7. 再平衡和退出规则；
