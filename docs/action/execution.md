知识只有进入日历、账户和清单，才会变成行为。执行系统的目标不是频繁操作，而是让正确动作容易，让冲动动作困难。

## 让资金按顺序流动

一种简单的发薪日流程：

1. 覆盖当月必要账单；
2. 补足应急金或短期目标；
3. 按 IPS 自动投入长期组合；
4. 留出计划内可选消费；
5. 不用月底“剩多少投多少”考验意志力。

投入金额可以是固定值或收入比例。收入波动较大时，使用“基础固定额 + 超额收入比例”可能更灵活。

## 一次性投入还是分批投入

如果一笔钱本来就属于长期投资，立即按目标配置投入能更早获得市场暴露；分批投入可能降低心理压力和短期择时后悔。选择要考虑：

- 目标期限；
- 当前组合与目标偏离；
- 资金规模相对总资产的比例；
- 自己面对短期下跌的行为风险；
- 分批期间资金放在哪里；
- 是否会无限等待“更好价格”。

无论选择哪种，都提前写出时间表。分批不是持续主观择时的借口。

## 交易前七问

任何计划外交易，先回答：

1. 它属于 IPS 中哪个目标和资产角色？
2. 原配置或产品的哪项基本假设发生了变化？
3. 信息来源是正式资料还是市场故事？
4. 全部成本是多少？
5. 对集中度和最大回撤有什么影响？
6. 如果价格立即反向 30%，我如何处理？
7. 等待 48 小时会损失什么确定的东西？

若无法书面回答，不交易。

## 用限价、频率和尺寸管理操作风险

- 了解市价单与限价单差异，尤其是流动性较低的 ETF；
- 避免在剧烈波动或底层资产休市时盲目成交；
- 单笔投入不要超过事先设定的比例；
- 固定处理日，避免全天盯盘；
- 下单后核对产品代码、份额类别、金额和状态；
- 保留成交与决策记录。

具体交易规则随市场和产品变化，应查阅交易场所及机构的最新说明。

## 账户安全也是投资能力

- 为金融账户使用独立强密码；
- 开启可靠的双重验证与通知；
- 不点击消息中的陌生开户链接；
- 只通过官方应用与网址操作；
- 定期检查授权设备和联系信息；
- 设置可信家人的应急知情方案，但不共享明文密码；
- 妥善保管合同、对账单和受益安排。

::: warning 防骗优先于收益
任何要求屏幕共享、验证码、远程控制或转账到个人账户的“客服/老师”，都应停止沟通并通过官方渠道独立核验。
:::
