投资政策声明（Investment Policy Statement，IPS）是你在冷静时写给未来自己的决策合同。当市场剧烈波动、热点出现或生活变化时，它告诉你按什么原则行动。

## 一份个人 IPS 的结构

### 1. 目的

用一句话写明投资服务于什么。例如：

> 本组合用于支持 20 年后的退休与长期购买力增长，不承担三年内的家庭刚性支出。

### 2. 当前约束

- 收入与稳定性；
- 应急金覆盖月份；
- 重要负债；
- 未来三年资金需求；
- 家庭责任；
- 不可接受的产品或风险。

### 3. 目标与期限

每个目标写金额、期限、优先级、弹性和资金来源。

### 4. 目标配置与区间

| 资产角色 | 目标比例 | 允许区间 | 选择原则 |
| --- | ---: | ---: | --- |
| 流动性 |  |  |  |
| 稳定器 |  |  |  |
| 增长引擎 |  |  |  |
| 其他 |  |  |  |

比例合计应为 100%。允许区间用于避免因为微小偏离频繁交易。

### 5. 投入规则

写明频率、金额或收入比例，资金不足时的优先级，以及大额一次性资金如何处理。

### 6. 再平衡规则

明确检查周期、触发阈值、使用新增资金优先级和交易前检查。

### 7. 禁止事项

例如：

- 不使用借款和杠杆；
- 不买无法解释的产品；
- 不凭排行榜、群聊或单一大 V 下单；
- 不让单一公司或主题超过约定上限；
- 不因市场预测临时改变长期配置；
- 不用短期目标资金补仓。

### 8. 复盘与修改条件

固定每季度轻复盘、每年完整复盘。只有当目标、期限、家庭、收入、法律税务或资产长期假设发生实质变化时，才修改政策。市场涨跌本身不自动构成修改理由。

<div class="key-idea">
一条规则如果无法被第三方判断“你是否遵守”，就还不够具体。“逢低买入”不具体；“每季度检查，偏离目标 5 个百分点时优先用新增资金恢复”可以执行。
</div>

## IPS 不是什么

- 不是保证收益的计划；
- 不是未来市场预测；
- 不是永远不能修改的誓言；
- 不是罗列很多产品代码；
- 不是越复杂越专业；
- 不是代替紧急生活决策的合同。

一份好的个人 IPS 应该短、清晰，并且家人能理解。

## 本课练习：先写一页版

不要等所有知识完美再写。先完成一页：

1. 投资目的；
2. 三条核心约束；
3. 目标资产配置；
4. 投入规则；
5. 再平衡规则；
6. 五项禁止事项；
7. 下次复盘日期。
