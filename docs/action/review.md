如果不记录，人会事后改写记忆：赚钱时认为自己早有判断，亏损时认为当初只是试试。决策日志让你有机会区分能力、运气和流程漏洞。

## 一条合格的决策记录

每次买入、卖出或修改规则前记录：

- 日期与决策；
- 对应目标；
- 当时配置与偏离；
- 使用的信息来源；
- 核心理由与关键假设；
- 三个失败情景；
- 预期持有期限；
- 重新评估条件；
- 当时情绪与信心区间；
- 是否符合 IPS。

不要写“看好后市”。写可检查的事实和条件。

## 复盘看什么

### 目标进度

目标金额、期限、累计投入和合理假设是否仍匹配？若有缺口，优先讨论增加投入、延长期限、调整目标，再讨论增加风险。

### 配置偏离

当前比例是否超出 IPS 区间？偏离来自市场还是计划外交易？是否触发再平衡？

### 成本与执行

实际支付了多少费用？是否频繁交易？自动投入是否正常？账户操作有没有失败？

### 行为纪律

有哪些时刻想追涨、割肉或更换产品？是否遵守冷静期？如果没遵守，流程如何修改？

### 产品与假设变化

基金基准、经理、策略、费用、规模、指数规则或组合角色是否发生实质变化？

## 不要只盯收益率

短期收益可能奖励坏决策，也可能惩罚好决策。可控指标更适合早期学习：

## 推荐复盘节奏

### 每月 10 分钟

确认自动投入、异常交易、配置是否明显越界。不要因为每月检查就每月交易。

### 每季度 30～60 分钟

更新净资产与目标进度，记录行为事件，必要时再平衡。

### 每年 2～3 小时

重新检查全部目标、家庭状况、现金流、风险承受能力、产品与 IPS。与家人共同完成更好。

### 重大事件时

结婚、生育、失业、重大疾病、迁居、购房或收入结构明显变化时，提前复核。

## 版本化你的 IPS

保留每次版本和变更记录：

| 日期 | 修改内容 | 原因 | 属于个人变化还是市场噪音 | 审核人 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

频繁修改是信号：可能原规则不现实，也可能正在用“优化”包装追涨杀跌。
