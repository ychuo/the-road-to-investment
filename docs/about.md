# 关于这套教程

「投资之路」是一套以**决策能力**为核心的开放式投资入门课程。

## 我们相信

- 投资的首要目标不是跑赢别人，而是实现自己的生活目标；
- 风险不是一个数字，而是目标无法实现的可能性；
- 资产配置通常比猜测短期涨跌更值得普通人投入精力；
- 低成本、广泛分散、长期持有是很好的默认起点，但不是无需思考的口号；
- 书面规则比临场意志力可靠；
- “不知道”和“暂不行动”都是专业的答案；
- 学习成果应由解释、作品和执行纪律验证，而不是短期收益。

## 课程范围

核心课程覆盖个人财务起点、风险收益、复利费用、市场机制、行为偏差、主要资产类别、基金、资产配置、分散再平衡、基金筛选、压力测试、投资政策声明、港股美股与全球配置、财务报表和企业估值、保险与住房、家庭治理、退休规划、固定收益、市场历史、证据判断、绩效归因和持续复盘。

基础路线不深入讲解：

- 技术分析、择时和短线交易；
- 期权、期货、融资融券和复杂衍生品；
- 加密资产实操；
- 房地产交易实务；
- 税务、保险方案和跨境账户的个性化建议。

进阶路线不应阻塞零基础学习者先建立基础系统。跨境税务、保险、法律和退休提取只提供核验与决策框架，不提供个性化结论。

## 免责声明

本教程仅供教育与一般信息交流，不构成投资、法律、会计或税务建议，也不构成任何产品的招揽、推荐或收益承诺。文中的例子不代表真实或未来业绩。

投资者应根据自身财务状况、目标、期限和风险承受能力独立决策，必要时咨询具有相应资质的专业人士。市场、法规、产品合同、费用和税收会发生变化，实际操作前请以监管机构、交易场所、基金管理人等发布的最新正式资料为准。

## 如何参与

这套课程适合边学边改。你可以在学习中持续记录：

- 哪些解释仍然太抽象；
- 哪些练习无法代入现实情况；
- 你在哪一步产生冲动或畏惧；
- 哪些内容需要增加案例；
- 作业量规是否真的能区分“做过”和“理解”。

这些反馈将决定后续版本，而不是单纯增加章节数量。
