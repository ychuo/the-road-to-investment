# 本地自动评分

把已填写的 Markdown 作业载入下方工具。内容只在当前浏览器内处理，不会上传到服务器。

<HomeworkScorer />

## 分数如何计算

| 维度 | 分值 | 自动检查内容 |
| --- | ---: | --- |
| 必填结构 | 25 | 11 份作业各自要求的小节是否齐全 |
| 完成深度 | 25 | 有效正文长度、是否遗留 TODO |
| 证据与时效 | 15 | 来源、链接、文件与日期线索 |
| 量化与可核验 | 15 | 金额、比例、期限、表格等 |
| 推理与风险意识 | 20 | 理由、条件、预案、风险与关键概念 |

## 如何理解结果

- **90～100**：结构优秀，可以进入严格人工复核；
- **80～89**：结构基本达标，重点检查事实与推理；
- **60～79**：仍有明显缺口，按分项建议补充；
- **0～59**：更接近提纲或未完成草稿。

分数不是投资能力证明，也不会评价组合能否盈利。以下内容必须由人判断：

- 事实是否真实、来源是否权威；
- 计算口径是否一致；
- 因果关系是否成立；
- 配置是否适合你的家庭；
- 风险假设是否足够保守；
- 税务、法律与产品规则是否最新；
- 你是否真能在压力下执行。

工具还会尝试检查包含“目标比例”的 Markdown 表格是否合计为 100%。这只是有限的一致性检查，不能覆盖现金流、估值或税务中的全部计算。

::: danger 禁止粘贴敏感信息
即使工具只在本地运行，也建议先删除身份证号、完整账号、地址、联系方式、验证码和交易凭证。金额可做一致比例缩放。
:::

命令行版本：

```bash
npm run homework:check -- 01
```
