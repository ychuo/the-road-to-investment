安全垫的作用不是赚取最高收益，而是为你购买**选择权和时间**。它让突发事件不必变成高息债务，也让市场下跌不必变成被迫卖出。

## 应急金要覆盖多少个月

常见起点是 3～6 个月必要支出，但真正的答案取决于生活结构。

可考虑提高到 6～12 个月的情况：

- 收入波动大、奖金占比高或自由职业；
- 家庭只有一个主要收入来源；
- 有老人、孩子或较高医疗责任；
- 行业就业周期长，重新找到工作需要较久；
- 心理上只有更高储备才不会焦虑。

可以从较低月份起步的情况：

- 双收入且行业相关性低；
- 工作稳定、保障充分；
- 家庭有其他可靠流动资源；
- 必要支出可快速下降。

$$
\text{应急金目标} = \text{月必要支出} \times \text{覆盖月数}
$$

## 应急金应该放在哪里

判断顺序是：

1. **能否及时取用**；
2. **本金波动是否足够低**；
3. **使用规则是否简单**；
4. 最后才是收益率。

它可以分成两层：一部分随时可用，另一部分允许稍低流动性但仍应以安全为主。具体工具需要核验赎回、到账、限额、费用和信用风险。

::: warning “低风险”不等于“没有风险”
货币基金、短债基金、存款和现金管理产品的机制不同。不要只看界面上的风险标签，应阅读产品文件和赎回规则。
:::

## 先还债还是先投资

把债务按实际成本和后果排序：

- 会滚动计息、成本高的信用卡和消费贷通常优先处理；
- 正常房贷等长期负债是否提前偿还，需要结合利率、流动性、提前还款条款与心理偏好；
- 无论如何，不要为了投资收益而忽视即将逾期的还款。

一种保守的顺序是：

1. 准备最小应急缓冲；
2. 停止新增高成本债务；
3. 集中偿还高成本债务；
4. 补足完整应急金；
5. 再逐步增加长期投资。

## 建立四个资金桶

| 资金桶 | 规则 |
| --- | --- |
| 日常桶 | 支付当月账单，避免透支 |
| 应急桶 | 只有真正意外才动用，用后优先补回 |
| 目标桶 | 每个 0～5 年目标独立记录 |
| 长期桶 | 接受短期波动，不为日常消费赎回 |

资金不一定非要放在四个账户里，但账目上必须能区分。
