投资从盘点开始，不从开户开始。看不清现金流和资产负债，就不知道有多少钱可以长期投入，也不知道自己能承担多少风险。

## 两张表，回答两个问题

### 现金流表：钱怎样经过你的生活

现金流表记录一段时间内的流入和流出，回答“我每月能留下多少钱”。

$$
\text{月度结余} = \text{税后收入} - \text{全部支出}
$$

$$
\text{结余率} = \frac{\text{月度结余}}{\text{税后收入}} \times 100\%
$$

示例：

| 项目 | 金额 |
| --- | ---: |
| 税后工资及其他稳定收入 | 15,000 元 |
| 必要支出 | 7,000 元 |
| 可选支出 | 3,000 元 |
| 债务偿还 | 1,000 元 |
| **月度结余** | **4,000 元** |
| **结余率** | **26.7%** |

必要支出与可选支出不一定有客观标准。关键是诚实：如果收入暂时中断，哪些支出很难取消？

### 资产负债表：今天站在哪里

资产负债表是某个时点的快照，回答“我拥有什么、欠了什么”。

$$
\text{净资产} = \text{资产总额} - \text{负债总额}
$$

资产可以先按用途分类，而不是只按产品名分类：

- **高流动性资产**：活期存款、货币基金等；
- **稳健型资产**：定期存款、符合期限需求的债券类资产等；
- **风险资产**：股票、权益基金等；
- **自用资产**：自住房、车辆等，通常不能直接拿来支付日常账单；
- **负债**：信用卡未还、消费贷、房贷等。

::: tip 不必追求假精确
房产、二手物品很难精确估值。使用保守、可解释的估计即可。第一次做表的价值是暴露结构，而不是得到一个漂亮数字。
:::

## 三个比净资产更有用的观察

### 1. 流动性

即使净资产很高，如果绝大部分锁在难以变现的资产中，遇到意外仍可能被迫借款或低价出售。

### 2. 现金流韧性

如果收入下降 30%，结余是否立即变负？如果一个月没有收入，哪些支出可以暂停？这比猜测明年收益率更紧迫。

### 3. 负债成本

偿还高成本债务，相当于获得一个接近债务利率、且无需承担市场波动的确定性改善。不要一边承担很高的借款成本，一边为了不确定的收益冒险。

## 本课练习

选择最近一个完整月份，完成：

1. 导出银行、支付工具和信用卡流水；
2. 先按“必要 / 可选 / 债务 / 储蓄投资”粗分，不要陷入几十个小分类；
3. 列出全部资产与负债，注明金额统计日期；
4. 计算月度结余、结余率和净资产；
5. 写下一个事实观察，避免道德评价。

好的观察：“外卖和通勤共占可选支出的 42%。”  
坏的观察：“我太不自律了。”
