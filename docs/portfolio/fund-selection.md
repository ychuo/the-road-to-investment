基金筛选应发生在资产配置之后。先确定需要“广泛股票暴露”或“中短久期高质量债券”，再在同类产品中比较。否则你会让营销页面替你制定配置。

## 六步筛选漏斗

### 1. 角色匹配

它要完成组合中的什么工作？产品类型、投资范围和风险是否匹配？不匹配就直接排除。

### 2. 规则清晰

对于指数基金，读懂指数选样、加权、调仓和集中度；对于主动基金，了解授权范围、基准、团队与风格。

### 3. 底层暴露

检查地区、行业、市值、久期、信用、杠杆、前十大持仓及与现有产品重合度。

### 4. 执行质量

指数基金关注跟踪差异、跟踪误差、规模、申赎与运营稳定性；ETF 还看流动性、价差和折溢价。

### 5. 全部成本

不要只看管理费：

- 管理费、托管费、销售服务费；
- 申购、赎回和转换费用；
- ETF 佣金与买卖价差；
- 组合内部交易成本；
- 可能的税费；
- 因复杂操作带来的时间与行为成本。

### 6. 可持续执行

购买渠道是否可靠？最小金额、自动投入、到账时间、份额类别是否适合？你能否五年后仍理解并持有？

## 常见文件读什么

| 资料 | 重点 |
| --- | --- |
| 基金合同 | 投资范围、比例限制、费用、申赎和持有人权利 |
| 招募说明书及更新 | 详细策略、风险揭示、管理人与服务机构 |
| 产品资料概要 | 核心信息快速入口，但不能替代必要时查全文 |
| 季报 / 年报 | 实际配置、持仓、运作说明、费用与变化 |
| 指数编制方案 | 选样、加权、调仓、发布日期与规则变更 |
| 交易所与监管公告 | 停复牌、重大事项与规则变化 |

优先使用官方来源，不依赖截图和二手总结。

## 比较时必须同类

股票宽基和短债基金不能只比收益率；同样叫“指数基金”，跟踪的指数风险也可能完全不同。比较前先固定：

- 相同资产类别和大致风险；
- 相同目标基准或相近指数；
- 相似份额类型和投资渠道；
- 合理长度且一致的观察区间。

## 红旗清单

- 你无法说出它跟踪什么或持有什么；
- 名称、宣传与实际持仓明显不一致；
- 费用复杂且无法估算；
- 依赖短期高收益排名；
- 规模或交易流动性不足以支持你的方式；
- 经理、策略、基准频繁变化；
- 与已有持仓高度重叠却没有新角色；
- 买入理由只能写成“感觉会涨”。
