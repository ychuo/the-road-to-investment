# 4.2 分散、相关性与再平衡

<div class="lesson-meta">
  <span>第 4 阶段</span>
  <span>建议用时 55 分钟</span>
  <span>核心框架：不押单一未来</span>

  <ul>
    <li>区分产品数量和有效分散；</li>

    <li>设计一条基于时间或阈值的再平衡规则。</li>

分散不是为了让组合每天都上涨，而是承认我们无法提前确定哪家公司、行业、地区或情景会胜出，因此避免任何单一错误摧毁计划。

## 买很多不等于分散

你可能持有十只基金，但它们的前十大持仓高度重合；也可能只持有两三只广泛基金，却覆盖大量不同证券。

检查四层集中度：

1. **单一证券**：是否被少数公司主导？
2. **行业与风格**：是否都偏向科技、成长或小盘？
3. **地区与货币**：是否依赖单一经济体或汇率？
4. **资产类别**：下跌时是否都依赖同一个驱动因素？

## 相关性描述“同向程度”

相关系数通常位于 -1 到 +1：

- 接近 +1：经常同向变化；
- 接近 0：线性关系较弱；
- 接近 -1：经常反向变化。

把低相关资产放在一起，可能降低组合波动。但要注意：

- 历史相关性不是固定常数；
- 估计区间不同，结果会不同；
- 危机时相关性可能突然上升；
- 低相关不代表资产本身优质；
- 复杂度和成本可能抵消分散收益。

## 再平衡是在恢复风险，而非预测市场

假设目标配置为股票 60%、债券 40%。股票上涨后变成 70%、债券 30%，组合承担的风险已经高于原计划。

再平衡就是卖出部分超配资产、买入低配资产，或用新增资金补向低配资产，使组合回到目标附近。

### 时间规则

例如每半年或每年检查一次。优点是简单，缺点是偏离很大时可能等待较久。

### 阈值规则

例如任一资产偏离目标比例 5 个百分点时处理。更贴近风险变化，但需要更频繁监控。

### 混合规则

固定周期检查，只有超过阈值才交易。对普通人通常更易控制交易频率。

::: tip 优先使用新增现金流
用后续投入买入低配资产，可以减少卖出、税费和交易摩擦。实际执行仍需考虑账户与产品规则。
:::

## 再平衡的心理难点

它要求你卖出近期表现好的资产，买入近期表现差的资产。上涨时会担心“少赚”，下跌时会担心“接飞刀”。所以规则要在情绪平静时写好。

再平衡并不保证提高收益，它首先控制组合不要悄悄漂移成与你目标不匹配的风险。

## 本课练习：写再平衡规则

完成以下句子：

> 我每隔 **___** 检查一次组合。若 **___** 类资产偏离目标 **___** 个百分点，我优先使用 **___** 调整；若必须交易，我会先检查 **费用、税务、流动性与产品限制**。我不会因为 **市场新闻或短期预测** 临时改变目标比例。
