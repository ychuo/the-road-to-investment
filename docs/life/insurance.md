# 8.1 风险保障与保险

保险的核心作用，是用确定的小额成本转移发生概率较低、但足以破坏家庭财务的巨大损失。它不是应急金的替代品，也不应仅以“返还多少”“演示收益多少”评价。

## 哪些风险适合保险

用发生概率与损失严重度建立四象限：

| 风险 | 常见处理 |
| --- | --- |
| 高频、低损失 | 通过预算自留，例如常规门诊 |
| 低频、低损失 | 应急金或预算自留 |
| 高频、高损失 | 优先预防，保险可能昂贵或不可保 |
| 低频、高损失 | 最适合通过保险转移 |

应急金处理短期现金冲击；保险重点处理医疗巨额支出、家庭经济支柱身故、重大责任事故等灾难性风险。

## 四类常见保障解决什么

### 医疗保障

报销符合合同约定的医疗费用。重点查看免赔额、报销比例、医院范围、药品和治疗限制、既往症、等待期、续保条件。

### 重疾保障

达到合同定义的疾病状态后给付一笔资金。它可弥补康复期收入中断或额外支出，但“疾病名称相同”不代表赔付定义相同。

### 定期寿险

在保障期间因约定原因身故或全残时给付，主要保护依赖被保险人收入的家庭成员。保障需求会随着子女独立、负债减少和资产积累变化。

### 意外与责任保障

意外险围绕外来的、突发的、非本意事件；责任险处理依法应对他人承担的赔偿责任。都必须阅读定义和免责。

## 估算寿险缺口

一个教学框架：

$$
\text{保障缺口}
= \text{家庭未来责任现值}
+ \text{债务与一次性支出}
- \text{可用金融资产}
- \text{已有保障}
$$

家庭未来责任可以包括一定年限的生活费、子女教育和老人赡养。不要把自住房全部视为可立即使用的保障资产。

## 储蓄型和投资型保险

当保险包含现金价值、分红或投资账户时，应把两部分拆开：

1. 保障成本是多少；
2. 保证利益是什么；
3. 非保证演示是什么；
4. 提前退出损失多少；
5. 内部收益率在不同年份是多少；
6. 与“单独买保障 + 单独投资”相比有什么优势和代价。

演示利率不是承诺，长期锁定流动性也是成本。

## 核心条款清单

- 投保人、被保险人、受益人分别是谁；
- 保障责任和给付条件；
- 等待期、免赔额与免责；
- 健康告知是否真实完整；
- 保证续保与普通续保的区别；
- 保费未来是否变化；
- 现金价值与退保损失；
- 理赔资料与时效；
- 职业、地区和医院限制；
- 监管批准或备案信息与销售资质。

::: danger 如实告知
不要因为销售人员口头表示“没关系”而省略健康信息。应以书面问询、合同和保险公司正式确认为准，保留沟通记录。
:::

## 案例：有房贷的新家庭

小周夫妻有一个孩子，剩余房贷 150 万元，家庭必要支出每年 18 万元。小周承担 70% 收入，现有可用金融资产 40 万元，公司提供基础医疗保障。

分析顺序：

1. 先确认社会保险和公司保障范围；
2. 保留应急金，不把全部 40 万当作寿险替代；
3. 估算若小周收入永久消失，家庭需要多少年过渡；
4. 加上房贷、教育等责任，减去可用资产和已有保障；
5. 优先比较保障责任简单、期限匹配的方案；
6. 不以返还或演示收益掩盖保障缺口。

这个案例没有一个脱离地区、年龄、健康和家庭选择的“标准保额”。
