# 课程地图

<div class="lesson-meta">
  <span>11 个阶段</span>
  <span>43 节核心课</span>
  <span>11 份里程碑作业</span>
</div>

这条路线特意把“选产品”放在后面。顺序本身就是课程的一部分：**生活保障 → 基本规律 → 资产机制 → 组合决策 → 执行纪律**。

前五阶段构成零基础必修路线；第六至十一阶段扩展到全球配置、企业分析、家庭生命周期、固收、证据和组合运营。按照每天两小时的节奏，可参考[十六周学习计划](/start/study-plan)。

## 第一阶段：站稳起点

<div class="stage-card">
  <span class="stage-number">STAGE 01 · FOUNDATION</span>
  <h3>先回答“我在哪里、要去哪里”</h3>
  <p>建立现金流与资产负债全景，设置财务安全垫，把模糊愿望改写成有金额、有期限、有优先级的目标。</p>
</div>

**课程**

1. [画出你的金钱地图](/foundation/money-map)
2. [建立财务安全垫](/foundation/safety-net)
3. [写下目标与期限](/foundation/goals)

**里程碑作品：个人投资起点报告**

- 月度现金流表；
- 资产负债表；
- 应急金目标与缺口；
- 三个分层目标；
- 当前阶段“可以做 / 不做”的清单。

## 第二阶段：理解规律

<div class="stage-card">
  <span class="stage-number">STAGE 02 · PRINCIPLES</span>
  <h3>建立分析任何产品都能使用的底层框架</h3>
  <p>理解收益与风险、复利与费用、市场定价和行为偏差。不预测下一次涨跌，但知道自己为什么可能犯错。</p>
</div>

**课程**

1. [收益、风险与不确定性](/principles/return-risk)
2. [复利、通胀与费用](/principles/compounding)
3. [市场如何给资产定价](/principles/market)
4. [识别自己的行为偏差](/principles/behavior)

**里程碑作品：产品风险解剖卡**

任选一个你持有或感兴趣的产品，不评价“会不会涨”，而是解释收益来源、主要风险、费用、流动性与适用目标。

## 第三阶段：认识资产

<div class="stage-card">
  <span class="stage-number">STAGE 03 · ASSETS</span>
  <h3>知道自己究竟拥有什么</h3>
  <p>从现金、债券、股票，到基金、黄金和 REITs，区分资产与包装，理解不同资产在组合中承担的角色。</p>
</div>

**课程**

1. [现金与债券](/assets/cash-bonds)
2. [股票：买的是企业](/assets/stocks)
3. [基金与指数基金](/assets/funds)
4. [黄金、REITs 与其他资产](/assets/alternatives)

**里程碑作品：四类资产比较报告**

用同一套维度比较四类资产，并为每类资产写下一句“它在我的组合中负责什么”。

## 第四阶段：构建组合

<div class="stage-card">
  <span class="stage-number">STAGE 04 · PORTFOLIO</span>
  <h3>从“哪个好”转向“如何协作”</h3>
  <p>以目标与风险承受能力确定配置，理解相关性、再平衡和基金筛选，用历史情境检验自己是否真能坚持。</p>
</div>

**课程**

1. [资产配置](/portfolio/allocation)
2. [分散、相关性与再平衡](/portfolio/diversification)
3. [读懂并筛选基金](/portfolio/fund-selection)
4. [压力测试你的组合](/portfolio/stress-test)

**里程碑作品：纸面模拟组合**

给出目标配置、选择逻辑、投入规则、再平衡阈值和至少三个坏情境下的预案。建议观察不少于四周。

## 第五阶段：开始行动

<div class="stage-card">
  <span class="stage-number">STAGE 05 · ACTION</span>
  <h3>把知识固化为规则</h3>
  <p>写一份个人投资政策声明（IPS），建立记录与复盘节奏。真正的毕业不是一次买入，而是拥有一套能重复执行的流程。</p>
</div>

**课程**

1. [写投资政策声明](/action/ips)
2. [制定投入与交易规则](/action/execution)
3. [记录、复盘与迭代](/action/review)
4. [毕业项目](/action/capstone)

**毕业作品：个人投资操作手册**

整合前四个作品，形成一份 3～5 页、家人也能读懂的决策手册。

## 第六阶段：走向全球

<div class="stage-card">
  <span class="stage-number">STAGE 06 · GLOBAL</span>
  <h3>分散单一国家风险，同时管理新增复杂度</h3>
  <p>理解港股、美股、跨境持有结构、汇率与税务风险，建立一只基金或多地区拼接的全球配置方案。</p>
</div>

**课程**

1. [为什么进行全球配置](/global/why-global)
2. [港股与美股市场](/global/markets)
3. [汇率、税务与账户风险](/global/currency-tax)
4. [构建全球组合](/global/global-portfolio)

**里程碑作品：全球配置附录**

完成家庭地域暴露图、路径比较、跨境风险登记与组合穿透检查。

## 第七阶段：企业分析

<div class="stage-card">
  <span class="stage-number">STAGE 07 · ADVANCED</span>
  <h3>从持有市场进阶到研究企业</h3>
  <p>阅读财务报表，判断商业质量，用情景和反向估值研究价格，建立可证伪、受仓位约束的研究流程。</p>
</div>

**课程**

1. [读懂三张财务报表](/advanced/statements)
2. [分析商业模式与质量](/advanced/business-quality)
3. [估值是一组假设](/advanced/valuation)
4. [建立研究流程](/advanced/research-process)

**里程碑作品：企业研究备忘录**

完成商业模式、连续财报、竞争、管理层、估值情景、反方论证和可证伪条件。允许以“暂不投资”为结论。

## 第八阶段：家庭财务

保险与风险转移、住房与房贷、家庭共同决策、应急接管、养老金和退休目标。

**作品：家庭财务安全计划**

## 第九阶段：固收进阶

债券定价、收益率曲线、久期、凸性、信用利差以及债券基金风险归因。

**作品：固收风险审计**

## 第十阶段：历史与证据

通胀利率、经济周期、泡沫危机、回测偏差，以及如何审查投资主张。

**作品：投资主张审计**

## 第十一阶段：组合运营

收益测量、绩效归因、退休提取与年度财富体检。

**作品：年度财富体检报告**

## 毕业标准

课程不以收益率判定毕业。满足以下条件即可：

- 五份基础里程碑作业全部完成；
- 每份作业按评分量规达到 80 分或修订一次；
- 能不看课程解释资产配置与再平衡；
- 能写出三种情况下“明确不交易”的理由；
- 模拟执行满四周，至少记录两次想冲动交易但遵守规则的时刻；
- 最终 IPS 有明确的目标、边界、配置、投入和复盘规则；
- 完整路线学习者另需完成全球配置、企业研究、家庭财务、固收、证据审计和年度体检作业。

> 收益率受市场影响，流程质量才是学习者能够控制的变量。
