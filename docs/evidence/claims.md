# 10.4 评估一项投资主张

“高股息更安全”“某指标可以逃顶”“定投永远不会亏”都属于投资主张。你不需要立刻同意或反对，而要把它改写为可检查的问题。

## 主张审查七步

### 1. 精确定义

“长期”“低估”“高胜率”分别是多少？适用于哪些市场、币种和期限？

### 2. 说明机制

为什么这个现象应持续？谁支付回报，承担什么风险？没有经济机制的统计规律更容易消失。

### 3. 指定比较基准

相对现金、同类指数，还是风险相同的组合？不明确基准，超额收益没有意义。

### 4. 检查数据

样本、起止日期、频率、复权、费用、税务、失败样本和异常值如何处理？

### 5. 寻找反证

在哪些国家、时期或情景失效？什么证据会让提出者承认错误？

### 6. 检查可执行性

信号发布时能否成交？资金容量、换手、滑点、账户和合规是否允许？

### 7. 检查利益关系

提出者是否出售课程、基金、荐股服务或持有相关资产？利益关系不代表观点必错，但影响证据审查标准。

## 证据阶梯

从弱到强大致为：

1. 个人故事和截图；
2. 单一历史案例；
3. 未披露方法的回测；
4. 透明、可重复的长时期数据；
5. 多市场样本外验证；
6. 有经济机制、经过同行审查且后续仍有效；
7. 在成本、税务和现实约束下可实施。

不要因为研究写得复杂就自动提升证据等级。

## 相关性不是因果

两个变量同时变化，可能因为：

- A 导致 B；
- B 导致 A；
- 第三个变量同时影响；
- 样本选择；
- 纯属巧合；
- 定义或统计方法造成。

投资策略如果依赖因果机制，必须解释并寻找自然实验、时间顺序或其他支持，而不是只展示拟合线。

## 贝叶斯式更新

不需要复杂数学，也可以这样思考：

1. 主张出现前，我认为它成立的基础概率多大；
2. 新证据在“主张为真”和“主张为假”时分别多容易出现；
3. 证据是否独立；
4. 更新信心，而不是从 0 直接跳到 100%；
5. 保留下一条会改变结论的证据。

## 案例：“连续三年冠军基金”

主张：连续三年排名靠前，说明经理能力强。

审查：

- 候选基金有多少，是否只看幸存者；
- 是同类风险基准还是所有基金混排；
- 超额收益来自风格、行业、杠杆还是选股；
- 团队和策略是否变化；
- 费后结果；
- 三年是否覆盖完整周期；
- 投资者是否能在业绩出现前识别；
- 买入后资金涌入是否影响策略容量。

结果可能仍值得研究，但原主张证据远远不够。
