# 10.1 通胀、利率与经济周期

宏观经济影响资产现金流与折现率，但“知道宏观叙事”不等于能预测市场。市场价格通常提前反映预期，资产对数据的反应取决于结果与预期之差。

## 名义变量与实际变量

$$
1+r_{\text{实际}}
=\frac{1+r_{\text{名义}}}{1+\pi}
$$

高名义利率不一定代表高实际回报。如果通胀更高，购买力仍可能下降。

## 通胀如何影响资产

- **现金**：名义稳定，购买力可能被侵蚀；
- **固定利率债券**：未预期通胀上升通常不利；
- **股票**：企业可能提价，但成本、需求和估值也受影响；
- **房地产与基础设施**：租金可能调整，但融资成本和政策同样重要；
- **黄金与商品**：在部分通胀情景有帮助，但关系不稳定。

不存在对所有通胀都完美的资产。需求过热、供给冲击和货币贬值带来的通胀，资产表现可能不同。

## 利率通过两条路径影响资产

### 折现率

利率上升，提高未来现金流折现要求，长期资产估值通常承压。

### 经济与现金流

利率影响贷款、住房、企业投资和需求，进而改变企业盈利与信用风险。

市场关注的不只是利率水平，还包括变化速度、期限结构和是否超出预期。

## 经济周期不等于市场周期

市场价格常在经济数据确认前变化。可能出现：

- 经济仍差，但市场因预期改善上涨；
- 经济数据很好，但市场因估值和紧缩预期下跌；
- 不同行业处在不同周期；
- 政策缓冲改变传统关系。

因此“等经济恢复再买”可能意味着价格早已变化。

## 四象限只是思考工具

用增长上升/下降与通胀上升/下降构造情景，可以帮助检查组合：

| 情景 | 可能的主要压力 |
| --- | --- |
| 增长上升、通胀下降 | 风险资产可能较友好，但估值仍重要 |
| 增长上升、通胀上升 | 利率、利润率和政策约束 |
| 增长下降、通胀下降 | 企业盈利与信用，优质债券可能有缓冲 |
| 增长下降、通胀上升 | 股债可能同时承压，家庭现金流更困难 |

这不是固定资产回报表，也不能用于精准择时。

## 案例：经济衰退但股票上涨

市场在衰退正式公布前已下跌，并开始预期政策转向和未来复苏。数据确认衰退时，价格反而上涨。事后说“衰退利好股票”同样错误；关键是价格之前包含了什么预期。
