# 信息源与核验

投资信息的问题通常不是“太少”，而是噪音太多。建立固定的信息层级能减少被营销和情绪影响。

## 信息来源优先级

### 第一层：原始正式资料

- [中国证监会](https://www.csrc.gov.cn/)及地方证监局公开信息；
- [中国人民银行](https://www.pbc.gov.cn/)、[国家金融监督管理总局](https://www.nfra.gov.cn/)等机构公开信息；
- [上海证券交易所](https://www.sse.com.cn/)、[深圳证券交易所](https://www.szse.cn/)、[北京证券交易所](https://www.bse.cn/)及基金相关基础设施公开资料；
- 基金管理人发布的基金合同、招募说明书、产品资料概要、定期报告和公告；
- 指数公司正式编制方案与公告；
- 上市公司法定披露文件；
- 银行或机构正式合同与费用表。

### 第二层：高质量解释

- 权威机构的投资者教育材料；
- 严谨教材和经过长期检验的经典著作；
- 有方法、数据和利益披露的研究报告；
- 能链接到原始资料的专业解释。

### 第三层：线索，而非依据

- 新闻报道；
- 博客、视频、播客；
- 社交媒体和群聊；
- 产品排行榜和平台推荐页。

第三层可以告诉你“该去查什么”，但不应直接触发交易。

## 五步核验法

1. **找原文**：截图和转述能否追溯到正式文件？
2. **看日期**：规则、费率、经理和持仓是否已经变化？
3. **查口径**：收益是区间、年化、税前、费前还是费后？
4. **找利益关系**：发布者是否靠销售、流量或持仓获益？
5. **找反例**：什么证据会推翻这条结论？

## 产品信息记录格式

每份作业中的关键事实使用：

```text
事实：
来源机构：
文件名称：
发布日期 / 数据截止日：
链接或文件位置：
我的解释：
仍不确定之处：
```

## 数据常见陷阱

- 只展示上涨区间；
- 用短期收益年化；
- 忽略已清盘产品造成幸存者偏差；
- 混用价格指数与全收益指数；
- 忽略费用、税费、价差和无法成交；
- 回测规则使用了当时未知的数据；
- 把相关性写成因果；
- 用平均值隐藏最大回撤和结果分布；
- 只展示最成功账户或策略。

## 对 AI 生成内容的核验

AI 可以帮助解释、比较结构和提出反例，但可能生成过时或不存在的规则、费率、产品和出处。涉及以下内容时必须回到正式资料：

- 当前法规与税务；
- 产品费率、申赎、持仓和风险等级；
- 交易规则与账户操作；
- 历史数据和具体数字；
- 专业资格与机构身份。

> 把 AI 当作学习伙伴和审稿人，不当作行情终端、持牌顾问或事实来源本身。
