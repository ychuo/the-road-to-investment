# 个人财务计算器

这些工具用于把抽象概念转化为可讨论的金额。所有输入只在当前页面计算，不会上传或保存。

<FinancialCalculators />

## 使用规则

1. 先写假设，再查看结果；
2. 至少计算保守、中性、乐观三组；
3. 不把平滑年化回报当作真实市场路径；
4. 将费用与通胀纳入长期计算；
5. 保留输入日期和来源；
6. 用结果比较方案，不把结果当作承诺。

## 尚未覆盖的变量

计算器为了教学而简化，未统一处理：

- 税务居民身份和具体税费；
- 市场回报波动与收益顺序；
- 产品申赎限制；
- 收入增长和支出结构变化；
- 养老金政策；
- 房屋交易和地方税费；
- 个性化保险、法律和继承问题。

在真正作出重大决策前，应建立更完整的现金流模型并核验正式规则。
