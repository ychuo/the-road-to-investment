# 推荐阅读

阅读不是为了堆书单。每读一本，最好输出一页：作者主张、关键证据、适用边界、反对意见，以及如何改变自己的规则。

## 投资与市场基础

- **《漫步华尔街》**：理解市场、指数投资与常见投资方法。注意不同版本中的市场与产品细节会过时。
- **《投资最重要的事》**：理解风险、周期、第二层思维与防守。它不是可机械执行的择时手册。
- **《聪明的投资者》**：安全边际、市场先生与投资者性格。部分具体产品与市场背景属于历史语境。
- **《共同基金常识》**：理解低成本、长期与指数化逻辑。阅读时区分美国制度与本地产品环境。

## 行为与决策

- **《思考，快与慢》**：认识直觉、偏差和决策噪音。它是广泛行为科学读物，不是直接投资策略。
- **《金钱心理学》**：理解财富行为、长期生存与个人差异。适合初学者建立价值观讨论。
- **《噪声》**：理解判断为何不一致，以及如何用流程减少随机误差。

## 企业与商业进阶

- **《巴菲特致股东的信》**：从所有者视角理解企业、资本配置与长期主义。
- **《财务报表分析与证券估值》类教材**：准备进入个股研究前系统学习会计与估值，不建议只读碎片文章。

## 官方投资者教育

优先阅读监管机构、交易所、基金管理人正式发布的基础规则、风险揭示和产品文件。具体链接会变化，可从[信息源与核验](/reference/sources)列出的机构官网开始。

## 阅读作业

每本书用下面五问复盘：

1. 作者最核心的一个主张是什么？
2. 它依赖哪些证据或历史背景？
3. 在什么情况下不适用？
4. 有哪些可靠反对意见？
5. 它是否需要改变我的 IPS？为什么？

若一本书让你立刻想大幅交易，先等待 72 小时，再回答第五问。
