# 案例实验室

每一节核心课程底部都有一个对应的虚构案例，要求你先作答，再展开参考分析。案例不会提供具体证券推荐，也不使用未来收益证明答案。

## 如何学习案例

使用四步法：

1. **冻结信息**：只使用情境中当时可获得的信息；
2. **写出选择**：行动、不行动或继续调查都可以；
3. **说明依据**：连接目标、期限、风险、成本和证据；
4. **查看分析**：比较遗漏的风险，不要求与参考答案措辞一致。

## 边界

案例中的人物、金额和情境均为教学构造，不代表真实产品或个性化建议。市场规则、税务、费率和法律权利应在实际决策时使用正式来源重新核验。
