# 投资之路

一套面向零基础个人投资者的系统课程，覆盖基础投资、港股美股、全球配置、企业分析、保险住房、退休规划、固定收益、市场证据与组合运营。它不提供“明牌”，而是帮助学习者建立一套能长期使用的决策系统：

> 先保住生活，再理解风险；先写规则，再投入资金。

## 适合谁

- 只接触过货币基金、短债等低波动产品；
- 希望理解基金、股票、债券与资产配置，但不知从哪开始；
- 愿意用 8～12 周学习，并完成可检查的作业；
- 目标是长期稳健地管理家庭资产，而不是短期暴富。

## 本地启动

需要 Node.js 18 或更高版本。

```bash
npm install
npm run docs:dev
```

构建生产版本：

```bash
npm run docs:build
npm run docs:preview
```

检查课程、案例、测验、完成清单和内部链接是否完整：

```bash
npm run content:audit
```

## 作业系统

基础与进阶阶段共有十一份可提交的里程碑作业。先创建个人作业副本：

```bash
npm run homework:new -- 01
```

填写 `homework/my-learning/` 中生成的 Markdown 文件后，执行自检：

```bash
npm run homework:check -- 01
```

也可以在网站的“本地自动评分”页面粘贴或读取 Markdown。内容不会上传。自动评分和命令行自检只能验证结构、证据线索、量化程度与完成度，不能判断投资结论是否正确。请同时使用课程量规进行人工复盘。

## 内容边界

教程以中国大陆普通个人投资者为默认语境，强调低成本、分散、长期和风险匹配。所有内容仅用于投资教育，不构成个性化投资建议，也不承诺收益。产品规则、税费和监管要求可能变化，实际决策前应核验官方资料。

## 目录

- `docs/`：VitePress 网站正文与主题；
- `homework/templates/`：作业模板；
- `homework/my-learning/`：个人作业目录（可纳入 Git 记录成长）；
- `scripts/`：作业创建与自检脚本。
